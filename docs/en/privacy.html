Privacy policy

Last updated: 7 November 2026 · applies to the browser extension “Intro course for SolidCraft” (3D course for SolidCraft).

In short

The extension collects no personal data, needs no account, sends nothing to any server and contains no ads and no tracking. Everything it stores stays in your browser.

What the extension reads

The extension only runs on app.solidcraft.io. To tick off tasks and place the pointing hand, it uses SolidCraft’s official browser API (window.solidcraft) to read the state of the open page: which tool or dialog is open, where the buttons are, which sketches and bodies the model contains and their dimensions, and SolidCraft’s language setting. This information is only evaluated in the browser and is neither transmitted nor stored. The extension never changes your models.

What the extension stores

  • In the SolidCraft page’s local storage (localStorage, key solidcraft-kurs:v1): chosen level and language, completed steps and tasks, position of the course panel and technical values for the checks (e.g. the number of bodies at the start of a step).
  • In the extension’s storage (chrome.storage.local): whether the extension is switched on and whether a reset of the course progress is pending.

This data never leaves your device. You can delete it at any time: right-click the extension icon → “Reset course progress”, or remove the extension or clear the site data of app.solidcraft.io.

Permissions

  • scripting – to show the course on app.solidcraft.io (can be switched off) and to reset progress on request.
  • storage – for the two settings above.
  • contextMenus – for the right-click menu on the icon.
  • Access to https://app.solidcraft.io/* – the only site the extension works on.

No sharing

No data is sold, shared with third parties or used for anything other than the course. The extension does not load any code from the internet.

SolidCraft and this website

SolidCraft is a separate service by Tangency Labs; its own privacy notices apply to SolidCraft. This project page is hosted on GitHub Pages; GitHub may process technically necessary access data (e.g. IP addresses) – see GitHub’s privacy statement.

Children

The extension is aimed at children and young people aged about 8 to 14. Since it collects no personal data, no children’s data is processed.
